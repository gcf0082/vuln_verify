# 压缩炸弹（Zip Bomb）

**适用**：被校验的主张是解压导致的压缩炸弹。

- **确认（是漏洞）**：解压时只校验压缩前体积或压缩包表面大小，未限制解压后实际写入量--攻击者构造高压缩比包（如 42.zip）致磁盘/内存耗尽。常见错误用法（以解压前大小检查替代实际写入量限制）：
  - Java：只查 `ZipEntry.getSize()`，未在读取流时限制字节数
  - Python：只查 `ZipInfo.file_size`，未在 extract 时限制总量
  - Go：只查 `zip.File.UncompressedSize64`，未在读取时限制写入量
- **证伪（非漏洞）**：解压过程中限制了实际写入的数据量（贴出限制代码）--仅依赖解压前大小检查不算有效防护。
