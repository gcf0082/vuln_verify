# 命令注入 - 参数可控

**适用**：被校验的主张是命令注入，且执行命令的参数来自外部可控输入。

参数可控不等于可注入--关键看参数能否改变命令语义。逐跳核实参数是否到达执行点、是否有有效约束：

- **确认（是漏洞）**：可控参数到达命令执行且无有效约束，能构造改变命令行为的 PoC：
  - 高危参数注入：`-o /path/output.txt`、`--output=` 等可覆盖任意文件或指定任意路径
  - 空格攻击：参数内注入空格改变命令行为（如 `rm` 经空格传入额外路径删除非目标文件）
  - 压缩包文件名解析：解压时文件名的空格或 `-` 开头被解析为命令参数
- **证伪（非漏洞）**：参数值有白名单校验或转义，上述注入向量均被阻断（贴出校验代码）。
- **无法确认**：参数是否到达执行点、校验是否覆盖存在不可补缺口。
