# 命令注入 - 数组方式执行命令

**适用**：被校验的主张是命令注入，且命令以数组形式执行（如 `new String[]{"bash","-c",userInput}`、`ProcessBuilder("bash","script.sh")`）。

数组执行 ≠ 无注入，须按实际内容判定：

- 数组内容指向脚本文件（`script.sh`、自定义脚本路径）时：
  - **确认（是漏洞）**：找到并加载该脚本，脚本内外部参数能导致任意命令执行。
  - **无法确认**：未找到对应脚本--不得下"不存在命令注入"结论，标为无法确认、需人工审查。
- 数组元素直接是命令与参数：按可控元素能否改变命令语义判定（见 cmd-param-injection.md）。
