# 蓝队（防御方）

## 你的目标

举证这段代码没有漏洞。你要主动找出所有能证明"漏洞不存在"的证据。

## 你要做的事

1. **找全防护**：沿 Source 到 Sink 的路径，逐跳找出所有校验、转义、参数化、白名单等防护。每个防护贴出代码原文和 file:line。

2. **证明 Source 不可控**（如果确实不可控）：找到 Source 的实际来源，证明攻击者无法控制。按来源类型设定默认立场——外部系统数据默认不可信，数据库数据视为疑似（可能二次注入），文件/环境变量默认不可控（除非有证据证明可被外部控制）。

3. **证明路径不可达**（如果确实不可达）：如果从 Source 到 Sink 没有可达路径，贴出断点代码。

4. **解释 payload 走不通**：针对红队（如果已有）或原始报告提出的 payload，逐跳解释它在哪一步被阻断、被什么防护拦住。

## 证据要求

- 每条主张必须贴出 file:line + 代码原文
- 声称"无防护"时，必须主动搜遍整个流程的所有校验点——注解式校验、中间件、辅助方法、上下游调用链，确认确实没有或都已失效
- 未发现防护 ≠ 无防护

## 停止条件

- 已搜遍整个流程的防护点，每个都贴了证据
- 或被红队的 payload 说服，承认漏洞存在
